# 啾莉恩 桌宠 🐱

<p align="center"><img src="assets/juju-idle.png" width="180" alt="Juju 桌宠"></p>

一只住在 Windows 桌面上的啾莉恩。完全本地运行、无任何网络上报，支持番茄钟、台词自定义、待办提醒、听歌联动等全套功能。

> 形象来源于啾莉恩角色设定，仅供个人使用，请勿商用。

---

## ✨ 功能总览

| 分类    | 功能                                          |
| ----- | ------------------------------------------- |
| 基础互动  | 左键点击切形态（带跳跃）、拖拽、甩出滑行、边缘吸附、探头（可一半伸出屏幕外）、双击摸头 |
| 形态系统  | 6 种形态：待机 / 站立 / 抱抱 / 听歌 / 生日 / 微笑           |
| 听歌联动  | 电脑播放任何声音→ 自动戴耳机，0.5 秒内响应                    |
| 番茄钟   | 专注/短休息/长休息时长全部可自定义，点击宠物查看剩余时间，今日完成统计        |
| 台词自定义 | 每个形态最多 10 条台词，支持时段问候/时间/日期变量，台词以换行为一条。      |
| 提醒    | 久坐提醒、喝水提醒、待办提醒（到点弹气泡 + 跳一下，提前 5 分钟预告）       |
| 自动行为  | 无操作 3 分钟开始散步、10 分钟睡觉（有 Zzz 粒子）、充电/断网提醒      |
| 系统集成  | 托盘菜单、开机自启、全局快捷键 Ctrl+Alt+J 召唤/隐藏、三档大小       |

## 🎮 基本操作

| 操作             | 效果                                         |
| -------------- | ------------------------------------------ |
| **左键单击**       | 循环切换形态：待机 → 站立 → 抱抱 → 生日 → 微笑（听歌形态由音频联动控制） |
| **左键拖拽**       | 移动位置；快速甩出去会带惯性滑行，撞墙会弹一下再吸附                 |
| **靠近屏幕左右边缘**   | 自动吸附贴边；**可以把半个身子拖出屏幕外探头**（永远不会完全消失）        |
| **右键**         | 打开完整菜单（和托盘图标右键相同）                          |
| **Ctrl+Alt+J** | 全局快捷键，一键召唤 / 隐藏宠物（找不到它的时候用这个）              |

> 小技巧：番茄钟进行中单击宠物，会告诉你「还剩多少时间、已完成几轮」，且不会误切形态。

## ⏱ 番茄钟

右键 → **番茄钟**：

1. **开始专注 / 停止番茄钟**
2. **今日已完成 N 个番茄 쮝** — 每完成一个专注 +1，跨天自动清零，重启不丢
3. **专注时长**：预设 15/20/25/30/45/60/90 分钟，或「自定义…」输入 1～180 任意分钟
4. **短休息**：5/10/15/20 分钟或自定义
5. **长休息**：15/20/30/45 分钟或自定义（每完成 4 轮进入长休息）

进行中：每个阶段结束前 1 分钟和 10 秒会主动提醒；切形态的台词也会带上你设定的时长。时长设置持久化，重启保留。

---

## 💬 台词编辑（自定义）

右键 → **形态** → **编辑台词…**

- 每个形态一个输入框，**每行一条台词**，切换到该形态时随机说一条
- 上限：每个形态 10 条、每条 60 字
- 支持**变量**，显示时自动替换：
  | 变量        | 效果                                                     |
  | --------- | ------------------------------------------------------ |
  | `{greet}` | 按时段问候：早上好 / 中午好 / 下午好 / 晚上好 / 夜深了（以 5/11/14/18/23 点分段） |
  | `{now}`   | 当前时间，如 `14:30`                                         |
  | `{date}`  | 当前日期，如 `10月30日`                                        |
  示例：`{greet}！现在 {now}，{date} 也要加油鸭 쮝`
- 把某形态的台词**全部删空**并保存 = 切换到该形态时不说话（不会被默认台词回填）
- 每个整点 Juju 会报时一次（睡觉时不打扰）

## ⏰ 提醒系统

- **久坐提醒**：以「键鼠有输入的累计时长」计算——累计活跃 45 分钟提醒一次；连续 5 分钟没操作视为已休息，重新计数
- **喝水提醒**：独立的 45 分钟倒计时（与久坐错开 22 分钟启动）；到点且你正在电脑前才提醒，人不在不会催
- **待办提醒**：提醒 → 添加待办提醒…，输入内容和时间；到点前 5 分钟预告一次，到点气泡 + 跳一下；待办列表里点某条即删除
- 久坐/喝水提醒可在菜单里分别开关

## 🌙 环境感知

- **听歌联动**：通过原生音频助手监测系统全部输出设备（含蓝牙耳机、虚拟声卡）的声音峰值，出声 0.5 秒自动切换到「听歌形态」，安静 0.5 秒恢复。可开关；助手异常退出会 3 秒内自动重启
- **自动睡觉**：无操作 10 分钟入睡（Zzz 粒子），有操作即醒。不变暗画面
- **自行散步**：无操作 3～10 分钟且醒着时，在桌面慢慢左右踱步
- **其他**：拔掉/插回电源、断网/恢复联网时会冒气泡提示

## ⚙️ 其他设置

- **大小**：三档 80 / 110 / 160 px
- **开机自启**：菜单勾选即可
- **全局快捷键**：功能开关里可关闭 Ctrl+Alt+J
- **显示/隐藏**：托盘图标单击或菜单项

所有设置保存在 `%APPDATA%\juju-desktop-pet\settings.json`（位置、大小、形态、时长、台词、待办、统计），删除该文件即恢复出厂。

## 🔨 从源码构建

### 环境

- Node.js 18+（建议 22）
- Python 3.10+（仅音频助手需要，依赖 `pycaw`、`psutil`、`comtypes`）
- Windows 10/11

### 步骤

```bash
# 1. 安装依赖
npm install

# 2. 打包音频监测助手（可选：不打包则用 venv python 直接跑脚本）
pip install pycaw psutil comtypes pyinstaller
cd tools
pyinstaller -F audio_watch.py
# 将生成的 dist/audio_watch.exe 复制回 tools/ 目录

# 3. 打包安装程序（国内网络建议先设镜像）
export ELECTRON_MIRROR="https://npmmirror.com/mirrors/electron/"
export ELECTRON_BUILDER_BINARIES_MIRROR="https://npmmirror.com/mirrors/electron-builder-binaries/"
npx electron-builder --win
```

产物在 `release/`：NSIS 安装版 + 便携版。

### 开发运行

```bash
npm start
```

> 注意：如果在沙箱/受限终端中运行，需确保 `ELECTRON_RUN_AS_NODE` 环境变量未设置，否则 Electron 会以 Node 模式启动、不显示窗口。

## ❓ 常见问题

**Q：点了宠物没反应？**  
重启一下应用。若托盘图标还在，先从托盘退出再启动。

**Q：播放音乐但没有切到听歌形态？**  
检查系统音量不为 0、播放设备正常；助手进程会自动重启，最多等 3 秒。音量很低的场景（<15% 主音量）可能低于检测阈值。

**Q：Ctrl+Alt+J 无效？**  
可能被其他软件占用。换个软件的快捷键，或在功能开关里关闭再开启重试（启动时会重新注册）。

**Q：杀毒软件报毒？**  
NSIS 打包的未签名应用可能被误报，加入信任即可；便携版同理。

**Q：屏幕分辨率变了 / 宠物不见了？**  
按 Ctrl+Alt+J 召唤；启动时程序也会自动把超出屏幕的位置拉回来。

**Q：数据/隐私？**  
完全本地运行。音频助手只读取系统音量峰值（0~1 的数值），不采集、不上传任何音频内容和网络数据。
